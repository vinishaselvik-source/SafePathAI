# 🛡️ SafePathAI

### AI-Powered Travel Safety & Smart Route Intelligence

**SafePathAI** is an AI-powered travel safety platform designed to help travelers make smarter and safer decisions before and during their journey.

Instead of providing only a route, SafePathAI combines **route analysis, travel risks, tourist places, emergency resources, and AI-powered recommendations** in one platform.

> **One Map. Real-Time Insights. Safer Travel Decisions.**

---

## 🚨 Problem

Travelers often need information from multiple sources before starting a journey:

- Which route is safer?
- Are there road risks or waterlogging?
- What tourist places are nearby?
- Where are hospitals and emergency services?
- What should I carry?
- What should I do in an emergency?
- Is the destination suitable for my type of trip?

This information is usually scattered across different applications and websites.

**SafePathAI brings these travel and safety insights together in one platform.**

---

## 💡 Solution

SafePathAI acts as a **personal travel safety companion** that helps users:

- Analyze travel routes
- Identify potential travel risks
- Discover famous tourist destinations
- Find nearby hospitals and emergency services
- Explore places on an interactive map
- Get AI-powered travel recommendations
- Plan personalized trips
- Receive safety suggestions
- Access SOS and emergency support

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/vinishaselvik-source/SafePathAI.git
```

### 2. Navigate to the project

```bash
cd SafePathAI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file based on `.env.example`.

Example:

```env
VITE_MAPTILER_API_KEY=your_maptiler_api_key
VITE_AI_API_KEY=your_ai_api_key
```

**Never commit your real API keys to GitHub.**

### 5. Start the development server

```bash
npm run dev
```

The application will be available through the local development URL shown in the terminal.

---

## 🔐 Environment Variables

The project may require API keys for external services.

Keep sensitive credentials inside `.env` and add `.env` to `.gitignore`.

Example:

```env
VITE_MAPTILER_API_KEY=
VITE_AI_API_KEY=
```
